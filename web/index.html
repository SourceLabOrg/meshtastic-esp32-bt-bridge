Zero-install Web Flasher

For full documentation, setup instructions, and troubleshooting, please see the
GitHub Repository README.

Welcome to the web flasher! This tool will install the transparent bridge firmware directly to your ESP32 via USB using WebSerial. You must use a supported browser (Chrome, Edge, or Opera) on a desktop operating system.

⚠️ Upgrading from a previous version?

When prompted by the installer, DO NOT check the "Erase device" box! If you leave it unchecked, all of your saved WiFi credentials and Bluetooth pairings will be preserved. Checking the box will wipe the device back to factory Setup Mode.
